# ScriptForge 1.1.0 implementation and validation

Implemented in the clean public checkout based on 422478f. The separate original
checkout and its existing uncommitted changes were preserved. No desktop release,
update manifest, signing key or GitHub Pages deployment is changed by this source push.

## Delivered

1. Shared canonical character identity for extended cues in editing, paste and
   Fountain import; extensions remain within one Character element.
2. Automatic writing sessions, screenplay segments, pause/resume, idle/editing
   windows, transactional local persistence, lease protection, crash checkpoints,
   gross/net counters, real paginator page deltas, stable scene IDs, and statistics UI.
3. Browser environment handling, browser-only current installer downloads, clear
   recovery/export language, shared editor/PDF/Table Read/Voice Library, safe static
   build and subpath preview, and a separate manual Pages workflow.
4. Application metadata synchronized to 1.1.0; dependency versions and signing/
   updater configuration are unchanged. License inventory hashes updated accordingly.

## Validation

- Unit suite: 363 passed.
- Existing browser suite: 176 passed after correcting the Saved label and
  Download-menu selector regressions; three optional model cases were skipped in
  the broad run and exercised separately with real model data.
- Production web scenarios at /ScriptForge/: 4 passed (editing/recovery/exports,
  cue identity, statistics resume/clear, and statistics quota failure isolation).
- Desktop frontend build and native Rust tests: passed; 7 native tests.
- Real Piper/model and mixed Table Read tests: 4 passed, including non-silent audio,
  persistence, previews, mixed playback, pause/resume/cancellation and invalid graph rejection.
- JavaScript syntax, production release configuration, public-source audit,
  529-dependency license inventory/Piper provenance, workflow YAML, and diff checks passed.
- Download asset matching was also checked against the real published v1.0.1 release.
- Statistics interface was rendered and visually inspected.

## Limits and release status

No new Windows/Intel installers or installed-update cycle were built for this source
push. These remain required gates before publishing desktop 1.1.0 through the
existing release workflow. Production Pages deployment has not been dispatched.
Browser data is device/origin-local. File System Access support and browser voice
availability vary; exports and local recovery remain available. Statistics allow
one writer per browser profile, preserve committed checkpoints after interruption,
and can lose the most recent uncommitted heartbeat interval. Editing time uses a
clearly documented 30-second activity window. See BROWSER-AND-WRITING.md for complete
metric semantics and deployment/testing instructions.
