ScriptForge keeps the working screenplay in its local library. Browser copies use IndexedDB and stay with that browser profile and site. Native copies are structured JSON records under the platform application-data directory, keyed by screenplay ID. Script titles can change independently of those IDs. Use Export to make a portable Fountain or PDF copy.

The app migrates existing records without writing to the old Fountain files. Desktop checks existing records on library refresh. The browser adopts them when opened. The exact editor model, IDs, settings, and recovery history carry over. If a registered external file differs, open its stored contents as a separate copy from the editor banner. Missing or unreadable originals leave the stored editor copy available. Use Import Fountain File for scripts that were never registered, live under a different browser origin, or need new permission. Dev uses its own database prefix and desktop application-data directory.

PDF export tries the current platform's color emoji font through Canvas and embeds the resulting bitmap. It uses attributed Twemoji artwork when a browser restricts Canvas or the glyph cannot be reliably rendered as one color symbol. Exports that use fallback show a notice. A glyph unavailable in both sources raises an error identifying its location. The PDF preserves emoji Unicode via ActualText. Search and copy behavior depends on the PDF reader.
