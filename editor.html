      MAKE YOURSELF AT HOME

      A little rhythm for your writing.

      ⌘ / Ctrl + Click
      Toggle continuation on a Character cue. Overrides stay in ScriptForge's browser document. Fountain files export the visible continuation text without internal metadata.
      ⌘ / Ctrl + F
      Find across the screenplay. Add Shift + H instead for Replace. Enter and Shift + Enter navigate results; Escape closes search.
      ⌘ / Ctrl + Shift + F
      Toggle Focus Mode. Escape returns to the writing room.
      ⌘ / Ctrl + 1–6
      1 Scene Heading · 2 Action · 3 Character · 4 Parenthetical · 5 Dialogue · 6 Transition. Works only in the screenplay editor. Some browsers reserve these keys for tab switching and may prevent interception.
      Plain text paste
      Tools → Paste as Plain Text bypasses screenplay detection until switched off. Single-line paste always inserts text normally.
      INT. / EXT.
      Typing either prefix at the start of action creates a scene heading.
      Enter
      After character or parenthetical, start dialogue. After dialogue, start action. Filled lines stay intact; only blank lines change in place.
      ⌘ / Ctrl + ] / [ / \
      Move the selected elements’ right text boundaries right / left by 5 points, or reset. Left indentation stays unchanged. Overrides stay in ScriptForge; plain Fountain omits custom margins.
      Shift + Enter
      A line break within the current element.
      Tab
      Dialogue → parenthetical; parenthetical → dialogue; character → parenthetical; empty character → transition. Filled lines create the next element below.
      Shift + Tab
      Advance backward through element types on a new line, or change a blank line.
      Character cues
      Names automatically capitalize while typing.
      ⌘ / Ctrl + Z
      Undo. Add Shift to redo.
      ⌘ / Ctrl + S
      Save to your local library.
      Backspace / Delete
      Delete text, or merge at an element boundary. Clearing a parenthetical also clears its brackets.
