# ScriptForge v1.2.0 — Customization, Analysis & Storage

## New features

- Train custom screenplay transitions.
- Train custom character dialogue tags.
- Analyze profanity using customizable categories, variations, and phrases.
- Confirm large deletions before removing screenplay content.
- Automatically manage local screenplay storage across desktop and browser.

## Improvements

- PDF export uses native system emoji artwork where supported and reports when it uses bundled artwork.
- Local editing, autosave, and crash recovery remain available. Migration preserves original Fountain files.
