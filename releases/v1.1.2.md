# ScriptForge v1.1.2

This maintenance release fixes five editor and PDF issues in the desktop and browser versions:

- PDF export now renders standard Unicode 17 emoji in color, including skin tones, flags and joined sequences. Original text stays intact, and PDF ActualText preserves emoji sequences for compatible readers.
- Return on an empty screenplay element creates a new, focused line. Consecutive blank lines survive recovery and Fountain saving.
- Emoji no longer switch the surrounding screenplay text to another font or size. The editor and PDF share fixed emoji sizing and grapheme-safe pagination.
- Single-click caret placement uses actual visible glyph positions at the current zoom, while preserving native drag and double-click selection.
- Cmd/Ctrl+B and Cmd/Ctrl+I toggle Fountain bold/italic emphasis for selected or subsequently typed text, including both styles together. Formatting is rendered without visible delimiters and retained in saved files and PDFs.

Existing screenplay libraries, preferences, writing statistics, Table Reads, Piper voices, native saving, backups and signed automatic updates remain compatible.

## Downloads and installation

Choose Apple Silicon or Intel macOS, or the Windows x64 installer. macOS packages remain ad hoc signed and unnotarized; Windows installers have no Authenticode publisher signature. Operating-system installation warnings or policy restrictions may apply. Updater packages are cryptographically signed and verified separately.

Emoji artwork is bundled locally from Twemoji 17.0.3 (CC BY 4.0, Twitter, Inc. and contributors). Emoji text extraction depends on PDF-reader ActualText support; unsupported nonstandard sequences still receive an explicit diagnostic. No user text is replaced with placeholder glyphs.

The GPLv3 corresponding-source archive and SHA-256 checksums accompany this release.
