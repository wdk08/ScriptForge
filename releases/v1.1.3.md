# ScriptForge v1.1.3

This focused update improves emoji appearance and editing while preserving screenplay formatting and PDF export.

- The editor now uses native system emoji, including Apple Color Emoji on macOS and Segoe UI Emoji on Windows.
- Emoji insertion, selection, deletion, undo/redo, and cursor scrolling preserve the writing position, including compound emoji and skin-tone variants.
- PDF exports retain the existing bundled color emoji artwork and Unicode text support.

## Downloads and updates

Choose the Apple Silicon or Intel macOS installer, or the Windows x64 installer. Existing installations can use ScriptForge’s signed automatic updater. The browser version is available through the project website.

Desktop packages are unsigned/unnotarized at the operating-system level. macOS may require approval in Privacy & Security; Windows SmartScreen may show an unknown-publisher warning. Updater payloads remain cryptographically signed and verified. Back up important screenplays before updating.
