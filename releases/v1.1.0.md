# ScriptForge v1.1.0

ScriptForge 1.1.0 adds Writing Sessions and a browser edition, with improved character recognition throughout the editor.

## Writing Sessions and statistics

Track writing sessions and subsessions automatically, with a 30-minute resume window, idle and background detection, and session history. Statistics include active writing time, gross and net word activity, page and scene changes, and daily activity. Undo, redo, moving text, and scene renaming are accounted for rather than counted as fresh writing.

Statistics stay on your device. Crash recovery restores the last persisted checkpoint; activity after that checkpoint may not be recoverable. See the [Writing Sessions guide](https://github.com/wdk08/ScriptForge/blob/v1.1.0/docs/BROWSER-AND-WRITING.md) for metric definitions and recovery limits.

## Improved character cue recognition

Character extensions such as V.O., O.S., CONT'D, and custom extensions use the existing shared character identity. Recognition works across lowercase typing, paste, and Fountain import, keeping character assignments and Table Reads consistent.

## ScriptForge in your browser

Use the [browser edition](https://wdk08.github.io/ScriptForge/) for screenplay editing, PDF and Fountain export, local recovery, Table Read, and the Voice Library. Its download menu offers the latest desktop installers.

Browser recovery is local browser data, not an independent screenplay backup. Export Fountain files for portable backups. Folder saving depends on browser support; desktop native storage remains available.

## Downloads and updates

Choose the Apple Silicon or Intel DMG for your Mac, or the Windows x64 installer. Existing desktop installations can use **Check for Updates**. Updater packages are cryptographically signed and verified independently of operating-system publisher signing.

**Installation limitations:** macOS builds are ad hoc signed, without Apple Developer ID signing or notarization, so Gatekeeper may require an explicit override. Windows builds have no Authenticode publisher signature; SmartScreen or Smart App Control may warn or block installation. See [INSTALLING.md](https://github.com/wdk08/ScriptForge/blob/v1.1.0/INSTALLING.md) for details.

Piper voices, Table Reads, PDF export, native file saving, and signed automatic updates are preserved. ScriptForge is GPLv3; the release includes its corresponding-source archive and third-party notices.
