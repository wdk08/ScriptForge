# ScriptForge v1.1.0

- Writing Statistics: automatic screenplay sessions and subsessions, 30-minute
  resume, idle/background detection, editing/active time, gross and net word
  activity, actual page changes, scene changes, daily activity and session history.
- Character cue extensions such as V.O., O.S., CONT'D and custom extensions work
  with shared character identity, lowercase input, paste and Fountain import.
- A production browser build shares the desktop editor, PDF exports, local recovery,
  Table Read and Voice Library. Browser-only downloads select current published
  desktop installers. A manual GitHub Pages workflow validates before deployment.

Statistics and browser data remain local to the device/browser. Export Fountain
files for independent backups. See docs/BROWSER-AND-WRITING.md for precise metric
semantics, crash limits, browser capabilities and setup.

Desktop filesystem operations and signed updates remain available. macOS builds
remain ad hoc signed/unnotarized; Windows builds do not have a publisher signature.
