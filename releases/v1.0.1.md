# ScriptForge v1.0.1

Smart Return splits every editable screenplay element at the cursor, keeps the
original type, and classifies the remaining text using the shared paste formatter.
The cursor starts at the new element; one Undo restores the complete operation.
Selected text is replaced normally and all unselected text is retained.

Parenthetical splits keep both parentheses on the original element and move only
the remaining inner text. Return immediately before the closing parenthesis still
advances to Dialogue. Shift+Return continues to insert a manual line break.

Recovery preserves the exact structured editor state. Temporary arrangements that
ordinary Fountain cannot express save literal text with an explicit warning that
a Fountain-only round trip may change element types. The live document is unchanged.

Piper, Table Reads, pagination, PDF export and signed updates remain available.
Mac builds remain ad hoc signed/unnotarized; Windows builds have no publisher
signature. See [installation guidance](https://github.com/wdk08/ScriptForge/blob/v1.0.1/INSTALLING.md).
