# ScriptForge v1.0.0

First public release of ScriptForge, a local screenplay writing room.

- Structured screenplay editing, undo/redo, automatic pagination, scene navigation and formatting controls.
- Fountain import/export, PDF export and editable title pages.
- Local folder saving, recovery snapshots and independent version-history backups.
- Custom margins, scene numbering, dual dialogue and dialogue continuation markers.
- Search/replace, character renaming, screenplay statistics and light/dark themes.
- Table reads using browser voices and compatible imported Piper models.
- Cryptographically signed in-app update support and Help → Check for Updates / About ScriptForge.

Install the package matching your computer: Apple Silicon Mac, Intel Mac, or Windows x64. Older development builds need a manual installation of this first updater-enabled release. Keep your chosen screenplay folder and application data when replacing the application.

**Installation warnings:** Mac downloads are ad hoc signed, without Apple Developer
ID or notarization; Gatekeeper may require an app-specific Open Anyway approval.
Windows downloads have no publisher signature and may show Unknown publisher or
SmartScreen warnings. Smart App Control or managed policies can prevent running
them. Do not disable system protections; see [INSTALLING.md](https://github.com/wdk08/ScriptForge/blob/v1.0.0/INSTALLING.md).

Tauri updater signatures remain mandatory; they do not remove OS installation
restrictions. Matching GPLv3 source, notices and checksums accompany the binaries.
No voice models are bundled. No claim of certified publisher identity is made.
